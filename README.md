# Homeboard

A self-hosted dashboard for a vertical monitor: calendar, to-do list, weather, and rotating background
pictures, running on a Raspberry Pi.

## Just want to use it?

Everything you need is in the **[`homeboard`](homeboard)** folder. Download or clone this repository,
then open **[`homeboard/START-HERE.md`](homeboard/START-HERE.md)** and follow it from the top — it walks
you through the whole setup with no technical background needed.

You can ignore the other two items in this repository:

- **`tests/`** — the automated test suite, only useful if you're changing the code.
- **`CLAUDE.md`** — notes for AI coding assistants (like Claude), not needed to run Homeboard.
